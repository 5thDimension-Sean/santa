# Notice & Attribution

This dataset contains 1,000 verified programs for Santa 2026 - The Elf Calculator scoring **127,280** instructions in total.
Every program is verified under the official competition rules (48 registers, exact integer division, `1 <= value <= value_limit`, <= 4,096 instructions, <= 128 KiB per cell).
